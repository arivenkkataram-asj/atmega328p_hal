# LCD Driver 16x2
This `lcd_hd44780.h` currently developed for the 16x2 lcd display which uses the hd44780 or equivalent build in controller.  This includes the 8 custom character. That can be used by API funtions.

## Overview
This LCD Driver has the multiple function that can be used for the application specific designs.  This driver supports for the 16x2 display module using 8 bit mode.

## Supported Features
1. Display size 16x2
2. Wiring D0 to D7, RS and En pins.
3. Cursor Control
4. Shift_display
5. Custom Character. 8 charater pre-build in driver.

## Non Supported Features
- 4-bit mode

## Controller Compatibility
1. Currently tested with the Atmega 328p.
2. In future tested with other microcontrollers.

## Design Implementation
1. This driver uses the 8-bit mode only.
2. depends on the `hal_gpio.h` for interact with the pins for Read and Write mode.

## Public API Description
### List of Public Functions
### 1. `lcd_display_init();`
This is used for the initilizing the input pins and enabling the Write mode operation.
#### For Example:
```c
lcd_display_init(d0,d1,d2,d3,d4,d5,d6,d7,rs,en);
```
- D0 - D7, Rs, En are the PinNumber to insert to initilize the LCD display.
- By default the cursor and blink is OFF state.
### 2. `lcd_display_string();`
This Display the string either Row 1 or Row 2.
#### For example:
```c
lcd_display_string("Hello! World.",row);
```
- For Selecting the row 
- row = 1 For the display string in row one
- row = 2 For the display string in second row

### 3. `lcd_cursor_blink();`
For the Setting the cursor  and Blink of Cursor
#### For Example:
```c
lcd_cursor_blink(cursor,blink);
```
- Cursor = 0 & Blink = 0
The both Cursor and Blink will be OFF.
- Cursor = 0 & Blink = 1
The Cursor is OFF and Blink will be ON.
- Cursor = 1 & Blink = 0
The Cursor is ON and Blink will be OFF.
- Cursor = 1 & Blink = 1
The both Cursor and Blink will be ON.

### 4. `lcd_clear();`
- This will Clear the full screen by using `lcd_clear();`
### 5. `lcd_cursor_return_home();`
- The Cursor will move to the starting position of the display using of `lcd_cursor_return_home();`.
### 6. `lcd_clear_line();`
- To Clear the Row by entring of the row no. For Clearing the row one by using `lcd_clear_line(1)`.
### 7. `display_on_off();`
- To turn on and turn off the display by using of this `display_on_off(state)` if state = 0 the display will be OFF. if state = 1 the display will turn on.  
- This will be helpful on the Sleep mode of microcontroller.
### 8. `rotate_display();`
- The display character will rotated either Left side or write side. 
#### Example:
- The Left side `rotate_display('L');`
- The Right side `rotate_display('R');`
### 9. `lcd_goto();`
- To move the cursor to the specific line and column.
- This will help in the Entering the Input values
#### Example:
- `lcd_goto(row,col);`
- According to row no and col no the cursor will move.
### 10. `lcd_write_char();`
- This will help to write the character where the cursor is placed.
- By using of the lcd_write_char('_');
- using of the single quation mark this is recommended character to display.
### 11. Display of Custom created Character/symbol
- The custom created Character/ Symbol can be accessed by the 0 to 7 number.
- using of `lcd_write_char(custom_character_number);`
- This will display the custom created character in LCD display.


## Limitation:
1. This can only used for the 16x2 LCD display
2. It uses the 8-bit. So more pins are consumed.

## Error Handlng
1. There will be some minor bug if misleading of the invalid pins and inputs.
